# Sawari · Drive Hyderabad

A browser 3D driving game on five famous Hyderabad routes, built with Three.js on real
OpenStreetMap streets in a simple low-poly style. Left-hand traffic, a right-hand-drive
car, traffic signals, AI traffic and turn-by-turn guidance.

## Run it

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # static site in dist/
```

The route data is already built in `public/data/`, so nothing else is needed to play.

## Website

The site has four pages around the game, each with a shared header and footer and a
light/dark theme (follows the system setting; the header toggle overrides it and is remembered):

| Page | File | Sections |
| --- | --- | --- |
| Home | `index.html` | hero, at a glance, why it feels like Hyderabad, routes, how it works, day and night, call to action |
| Routes | `routes.html` | page intro, all five routes in detail, difficulty guide, practice tips, call to action |
| Features | `features.html` | page intro, driving, streets and city life, dashboard and controls, time of day and graphics, call to action |
| About & FAQ | `about.html` | page intro, why it exists, how the city is built, FAQ, safety notice, credits |
| The game | `play.html` | (the driving game; `play.html?route=charminar` pre-selects a route) |

Every page exists in English (site root) and in Hindi, Urdu (right to left) and Telugu under
`/hi/`, `/ur/` and `/te/`; the header's language menu links between them. Translations are
hand-written in `tools/site-translations.py`, one entry per English phrase. The build stops if a
translated page still contains an English phrase, so add new wording there too.

The pages are generated by `tools/build-site.py` (SEO settings in `tools/seo.py`); styles are in
`src/site.css`, behaviour in `src/site.js`, screenshots in `public/img/` (WebP, 800 and 1600 px).

### Publishing and search engines

The live site is https://sawari.airacode.online (deployed from `main`). Canonical links, the
sitemap, social cards and share buttons all use that address by default; to build for another
address, set `SITE_URL`:

```bash
python tools/build-site.py                                   # https://sawari.airacode.online
SITE_URL=https://staging.example.org python tools/build-site.py
npm run build
```

- Serve the site from the domain root over HTTPS, and configure the host to use `404.html` for
  missing pages.
- Each page has its own title, description, canonical link, `hreflang` links to its other
  languages, Open Graph and Twitter cards (`public/og-image.jpg`) and JSON-LD structured data
  (organisation, website, the free browser game, breadcrumbs, the route list and the FAQ).
- `public/sitemap.xml` lists all 16 pages with their language alternates; `public/robots.txt`
  points to it. Submit the sitemap in Google Search Console and Bing Webmaster Tools.
- The game (`play.html`) is not part of the SEO set-up and is not listed in the sitemap.

## Controls

| Key | Action |
| --- | --- |
| ↑ / W | Accelerate |
| ↓ / S | Brake; hold at a standstill to select reverse |
| ← → / A D | Steer |
| Space | Handbrake |
| Q / E | Left / right indicator (cancels itself after the turn) |
| C | Chase view or driver's seat |
| Mouse drag | Look around (double-click recentres) |
| R | Return to the route |
| M | Sound on/off |
| Tab | All controls |
| Esc | Pause |

Traffic can be set from None to Dense (about 80 vehicles around you: cars, SUVs, autos, buses, mini trucks, scooters and motorbikes).

A gamepad also works: left stick steers, RT/LT throttle and brake, LB/RB indicators, Y camera.

## What is checked

Faults are shown as they happen and listed in the debrief with advice: speeding, driving
right of the centre line, wrong way on a one-way road, leaving the road, running a red
light, collisions, and turning without an indicator.

## How it is built

```
tools/routes.config.mjs   route waypoints (lat, lon, road name, heading)
tools/fetch-osm.mjs       downloads OSM data per route from Overpass -> tools/raw/
tools/build-data.mjs      routes, flyover heights, buildings, trees, signals -> public/data/
src/world/                world mesh builder, road index, landmarks
src/car/                  car model with cockpit, physics
src/game.js               game loop, HUD, rules, traffic, guidance
```

To change a route, edit `tools/routes.config.mjs`, then run `npm run fetch-osm` (only
needed for new areas) and `npm run build-data`. The builder prints the roads each route
uses so you can check it.
